# 🌿 Leaf Lens

An AI-powered plant disease detection app built with Flutter. Take or upload a photo of a plant leaf, and the app sends it to a cloud AI vision API to help identify possible diseases.

## Features

- Capture a leaf photo with the device camera or pick one from the gallery
- Sends the image to a cloud AI vision API and displays the analysis result
- Handles camera and storage permissions at runtime
- Stores the API key locally on the device

## Tech Stack

| Area | Tools |
| --- | --- |
| Framework | Flutter, Dart |
| Networking | `http` |
| Image input | `image_picker` |
| Local storage | `shared_preferences` |
| Permissions | `permission_handler` |
| AI analysis | Cloud AI vision API |

## How It Works

1. The user takes a photo of a leaf or selects one from the gallery.
2. The app sends the image to the AI vision API over HTTP.
3. The API's response is parsed and shown in the app.

## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- An Android or iOS device or emulator
- An API key for the vision API used by the app

### Run locally

```bash
git clone https://github.com/sreerag-sankar-ps/Leaf-Lens.git
cd Leaf-Lens
flutter pub get
flutter run
```

## Disclaimer

Results are generated by an AI model and may be inaccurate. Leaf Lens is a learning project and is not a substitute for advice from an agronomist or plant pathologist.
